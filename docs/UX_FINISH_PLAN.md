# Scorecaster easy-use completion plan

This temporary planning document records the UX finish scope before implementation. It will be replaced by the merged release notes.

- Reduce primary web navigation to the six user tasks that matter.
- Move advanced, account and system tools into a clearly labeled secondary menu.
- Make `/agent` the canonical Agent V10 page and redirect the obsolete `/agent-v7` route.
- Rebuild the home page around a three-step paper-only flow.
- Replace outdated Agent V9 dashboard metrics with current Top Picks decision fields.
- Add a Finnish help page with plain-language definitions and task links.
- Add mobile-friendly bottom navigation for the core web tasks.
- Keep all legacy routes available through advanced tools or redirects.
- Preserve the no-real-money product boundary.
