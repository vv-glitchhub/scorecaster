# Scorecaster UX V2

This implementation phase is based on the mobile production review recorded on 2026-07-31.

## Goals

1. Today and AI Feed must never look broken when there is no publishable model edge.
2. Match cards must show one clear primary choice and a reproducible AI explanation.
3. Empty Top 3 and accumulator containers must be replaced by useful guidance.
4. Profile must focus on the user, local paper performance, preferences and account state.
5. Operator tools must remain available only through the separate More > Advanced/operator section.
6. Mobile typography and card density must remain readable on narrow screens.

## Product boundary

- Paper-only
- No automatic or real-money execution
- No invented probability when model evidence is missing
- Public formulas and source attribution remain available through /transparency
